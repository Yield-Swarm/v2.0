# YieldSwarm — CLAUDE.md
## What this app does
YieldSwarm is a DePIN-Native Yield Intelligence platform — an autonomous AI system that optimizes yield across DePIN hardware fleets, privacy-asset mining, and cross-chain DeFi.
## Stack
Express.js + EJS + PostgreSQL (Neon) on Render. Cloudflare for SSL.
## Directory map
- `server.js` — Express entry point (~136 lines). Owns: middleware registration, route mount call, app.listen. Does NOT own route logic.
- `routes/index.js` — Consolidated route mount file. All `app.use()` registrations extracted from server.js (prevents 300-line ceiling).
- `routes/` — Individual route handlers (Express Routers). 516 route files. Mount via `routes/index.js`.
- `ecosystem.config.js` — PM2 cluster config (4 workers, 1GB max mem, crash-resistant).
- `scripts/deploy-azure.sh` — One-command Azure VM setup (Node 20, PM2, Nginx, UFW firewall, systemd service).
- `scripts/nginx.conf` — Nginx reverse proxy (HTTP→HTTPS, port 3000 proxy, rate limiting, Cloudflare SSL).
- `services/` — Business logic: swarm-orchestrator, cohort-council, growth-hunter-agent, oracle-eye-agent, risk-sentinel-agent, treasury-agent, alliance-agent, chantico-hearth (SepETH #2 Hearth Engine — vault monitor, yield heatmap, LP routing, H-K-a-a-S), ovhcloud-pool-api (2miners ETH/KAS/ZEC pool API), ovhcloud-mining-monitor (OVHcloud GPU instance + revenue sync, activates when credentials land), + 14 more agents and utilities
- `db/` — Query functions: `index.js` (Pool) + 65+ entity files (arena, fleet, yield-dashboard, gpu-mining-clusters, cpu-mining-clusters, model-training, co-springs-referrals, chantico-hearth, etc.)
- `locales/` — Translation bundles: en, es, pt, fr, de, ja, ko, zh, ar, ru. `public/css/` — Stylesheets (theme.css).
- `lib/` — Utilities: landing-context, multi-model-router, polsia-ai, llm/router.js (Kimi/SuperGrok/Claude/Codex/o1/o3), kaleidoscope/, scheduler/, mining/pool-manager.js (GUNGNIR·FORGE: 22 Z15 Pro dual-mining); `middleware/` — request-logger, rate-limiter, error-handler, i18n, admin-auth
- `views/` — EJS templates: all public pages + admin views. `views/partials/nav.ejs` shared nav (5 tabs: Home/Earn/Governance/Team/Missions + Corporate DUNA).
- `migrations/` — Migration files (timestamp-prefixed .js). `migrate.js` — Migration runner for Neon PostgreSQL
- `github-repos/` — Open-source repo content + mission.control (SuperGrok↔Polsia shared command layer): yieldswarm-app, yieldswarm-agents, yieldswarm-docs, sunset-bridge, agent-simulator, depin-dashboard, helium-deployment-guide, polsia_infra (mission.control/integrations/status.json + commands/pending|completed.json + execution-log.json)
- `cloud-deploy/` — Provider deploy scripts: gcp/ (GPU mining, vLLM, Cloud SQL, Secrets), aws/ (ECS agents, SageMaker LLM), alibaba/ (ECS + vLLM), dns-wiring.sh (Cloudflare DNS all providers)
- `mining/` — Rig configs: config-z15-pro.js (22× Z15 Pro, ZEC/ZEN dual), config-kaspa.js (KHeavyHash), config-doge-ltc.js (Scrypt DOGE/LTC), config-gpu.js (RTX 4090: ERG/CFX/RDD), randomx-xmr.json (CPU mining)
- `llm-stack/` — LLM deployment: vllm-config.yaml (3 tiers), prometheus.yml, vllm-multi-provider.sh (GCP/AWS/Alibaba vLLM), ollama-modelfile, fine-tune.sh
- `depin-desktop/` — Desktop Node Controller source (Electron app for Windows). Build with `npm run build` → yieldswarm-depin-desktop-setup.exe (NSIS). src/: main.js, grass-node.js, earnings-store.js, auto-start.js, renderer.html.
- `depin-apk/` — Capacitor Android APK source (Prong A). JavaScript web app wraps yieldswarm.polsia.app/depin-node. Android native: NodeService.java (foreground service + 5-min heartbeat), BootReceiver.java (BOOT_COMPLETED auto-start), MainActivity.java (BridgeActivity). Build: `depin-apk/scripts/build-apk.sh` (requires JDK 17 + Android SDK locally — cannot build in sandbox). APK output: `build/yieldswarm-depin-node.apk`.
- `jobs/gpu-mining-monitor.js` + `jobs/cpu-mining-monitor.js` — GPU/CPU cluster monitoring (Akash/Vast.ai/Lambda/BlueForge/OVHCloud/Azure). 15-min crons. Coins: ETH/ETC + Kaspa + ERG/CFX (GPU), XMR/IRON (CPU).
